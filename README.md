# Global Tick Time Scale: Updated

Requires Factorio 2.1.24 or later.

Choose a target update rate and adjust simulation rates to preserve the game pace. This fork retains saved map baselines when migrating an existing time-scaled factory.

Choose the target rate in startup settings. Runtime options control day/night length, pollution, enemies and player crafting. Saved original values remain available when an adjustment is disabled. Safe mode disables runtime adjustments while retaining imported state.

Replace GTTS with this mod, keeping its settings. Both versions cannot be enabled together because they define the same prototypes. Factorio native ownership migration transfers the original saved state before initialization. Conflicting existing destination values stop migration instead of overwriting data.
